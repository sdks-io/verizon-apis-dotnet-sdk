
# Hpl Custom Fields

User assigned custom fields to use for fitering

## Structure

`HplCustomFields`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `Key` | `string` | Optional | key property<br><br>**Constraints**: *Minimum Length*: `3`, *Maximum Length*: `32` |
| `MValue` | `string` | Optional | value of the key property<br><br>**Constraints**: *Minimum Length*: `3`, *Maximum Length*: `32` |

## Example (as JSON)

```json
{
  "key": "key4",
  "value": "value6"
}
```
