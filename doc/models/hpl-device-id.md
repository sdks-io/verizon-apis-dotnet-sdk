
# Hpl Device Id

Identifier object pairs of kind/id

## Structure

`HplDeviceId`

## Fields

| Name | Type | Tags | Description |
|  --- | --- | --- | --- |
| `Kind` | `string` | Optional | The type of ID. This can be IMEI or ICCID. |
| `Id` | `string` | Optional | The ID value. |

## Example (as JSON)

```json
{
  "kind": "kind4",
  "id": "id6"
}
```
